# Archive Rules

Archived working notes. Files here are superseded but retained for reference.
Agents should not load these by default.

## Naming

Canonical form: `<YYYY-MM-DD>-<slug>.md`, where the date is when the file was
archived and the slug describes the content
(e.g. `2026-07-09-auth-rework-handoff.md`). The leading ISO date keeps entries
chronologically sortable.

## Organization

Group by artifact type in a parent subfolder when one applies — archived plans
go under `plans/` (`context/.archive/plans/<YYYY-MM-DD>-<slug>.md`); discovery
audits and handoffs stay at the top level. Create the subfolder on demand.
